2 Test it

    
Start a new session in your agent and paste this. It only checks that the agent can see Mirrorly; nothing is opened.

    
Find the Mirrorly MCP server's mirrorly_status tool. Its name may have a prefix, like mcp__mirrorly__mirrorly_status, and if your tools load on demand, search your tools for "mirrorly" first. Call it and reply with exactly what it returns. Only if no Mirrorly tool exists after searching, reply with: MIRRORLY NOT INSTALLED

    

      
"Mirrorly MCP is working … Pages open in the user's Firefox"

      
All set: pages open in this Firefox, in a background tab. The status above shows Connected.

      
"Mirrorly MCP is working … The Mirrorly extension is not connected"

      
It works, using headless Firefox. To use this Firefox (and your logins), turn on the switch above and test again; it connects within a few seconds.

      
"MIRRORLY NOT INSTALLED"

      
The app you're testing in didn't load Mirrorly. Check the install command listed the app with ✔ and ended with ✔ Verified, then fully quit and reopen the app (in VS Code, reload the window). npx -y github:dazecoop/mirrorly status lists which apps have it.

The tools

    

      
mirrorly_open

      
Loads a page in a phone: device, browser (Safari, Chrome, Firefox), light or dark, landscape. Again to reload.

      
mirrorly_scroll

      
To the top or bottom, a position, by an amount, or to a CSS selector.

      
mirrorly_screenshot

      
The phone with its browser bars, just the page in view, or the whole page. Returned as an image and saved as a PNG.

      
mirrorly_devices

      
The devices on offer, and the browsers each can be shown in.

      
mirrorly_status

      
Whether pages open in this Firefox or headless, and what's open.

    How it works & privacy
    
Everything stays on this computer. With the switch on, Mirrorly connects to ws://127.0.0.1:47616, where only Mirrorly's agent tool listens, and only while an agent app is running it. Each agent session gets its own phone in a background tab of this window; your sidebar and tabs are left alone. An unused agent phone closes after 10 minutes.

    
With the switch off, agents can still use Mirrorly, in a separate headless Firefox without your logins.

    
The page is drawn by Firefox's engine, so engine-specific CSS can differ slightly from Safari or Chrome.

    Troubleshooting
    
    
      
  • Always "waiting for an agent": that's normal when no agent app is running Mirrorly. Its server starts with the agent session and stops after 10 idle minutes; Mirrorly checks for it every 5 seconds.
    • 
      
  • "MIRRORLY NOT INSTALLED": run npx -y github:dazecoop/mirrorly status in a terminal. It lists each agent app, whether Mirrorly is installed there and whether it starts.
    • 
      
  • Pages open headless even with the switch on: check the port under Options matches MIRRORLY_PORT in your agent's config (if set).
    • 
      
  • Headless Firefox won't start: install Firefox, or set MIRRORLY_FIREFOX to its binary.
    • 
      
  • A site won't load: some sites refuse to be shown in a frame, and Firefox keeps extensions off addons.mozilla.org and a few Mozilla sites.
